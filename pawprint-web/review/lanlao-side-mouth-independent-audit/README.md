# 侧面嘴部内壁与遮挡独立核验

基于 `/private/tmp/lanlao-side-independent.blend` 与 `/private/tmp/lanlao-side-surgery-sync.blend`，2026-11-09 的局部实验，不是正式模型。原主网格所有原有形态键坐标签名在5位小数精度下均可匹配；66组权重签名发生变化，因实验有意更改下颌绑定，仍需完整行走等动作回归，不可视为已保留动作。

新增 Side_Oral_Lining：136点93面，带6个形态键。1、8、12、16、20、30、35、38帧各80个开放边、1条非流形边，闭嘴帧1和38各26个零面积面，其余抽样帧为0。统计范围仅新侧面内壁，并未覆盖其他对象；有开放边不自动证明可见漏缝，但不支持其已形成完整闭合口腔。

按侧面600×600正交预览相同相机及姿势对少量像素做射线测试：白色竖线附近(228,387)和(250,387)分别命中脸部原始外皮材质面20529与22578；周围样本命中口腔内壁。说明至少这些浅色断面是外皮几何仍穿过张口区，不应只调整口腔内壁材质。抽样不代表全部图像。

两个脚本所引用的临时输入需要按实验文件的最终保存路径替换。任何代码/指标均不代表实际自然度、原动画安全、网页或设备验证，不能直接接入网站。

## 侧壁形态键与动态外缘间距

对 `lanlao-side-surgery-sync.blend`，按 Basis 坐标和骨骼权重匹配 68 个侧壁外缘点和主网格点，其中14处有多个候选；取各形态键位移误差最小的候选，六个形态键位移最大差为0。抽样现有张嘴动画帧：1帧最大世界间距约 3.1e-8 模型单位，8帧约 7.4e-5，20/30帧约 2.41e-4，38帧约 3.1e-8；20帧平均约 1.14e-5。单位为该模型坐标系，匹配歧义、取最优可能低估误差；不是整个模型或行走/毛发动画的验证，也不证明外缘完全焊合。日志见 `continuity.log`。

## 外皮跨唇面诊断

对第20帧白色断面射线命中的皮肤面20529，模型网格中四点权重不一致：25566、24571、19059 下颌权重为0，25560 下颌权重为0.72；前三点 z≈0.579–0.581，25560 从基形 z=0.579 下移到 z≈0.5605。这张外皮面张口时横跨上下唇，是白色桥状遮挡的一个直接来源。另一个样本面22578的顶点权重分布为约0.11–0.48，下颌变形呈渐变，需结合局部面片和切口独立检查。详见 `faces.log`；数值只针对这两个面及当前模型，不可外推所有白纹。可能修法是在保持UV、形态键和权重时完整拆分上下唇面并重建口角，而不是直接删除面后留下缺口。

## 清理重复顶点面与内壁加厚

检测到一条含8面连接的非流形边以及面 `[3,4,4,5]` 等重复点面；构面去除相邻重复点并折为三角后，8个抽样帧局部非流形边从1降为0，但闭嘴帧仍各有26个退化面。又将32个下内壁点的所有形态键高度下降约0.0003模型单位，局部在8帧中的退化面降为0，80条开放边仍存在（独立对象边界亦计入），不代表整体闭合。原皮毛网格6键坐标签名5位小数0丢失，66组权重签名有变。具体见 `clean-audit.log` 与 `thickness-audit.log`。

加厚后的68个外侧同位匹配点在8帧的数值间距没有变化，帧20最大约0.000241模型单位，存在14处配对歧义；不等于完美焊合。扩大手术边界范围之外21754张原皮肤面的静态几何+逐角UV签名5位小数0缺失，范围内及动画未知（`uv-outside.log`）。所有检测均仅限实验副本，视觉仍不自然，不能作为完成或上线验证。

## 真实侧唇焊接与厚度回退修复

对源 `lanlao-side-thickness.blend` 与初始 `lanlao-side-actual-weld.blend` 独立核验：旧主网格六组键坐标、权重、22,277张旧外皮面的几何与逐角UV签名在5位小数下0缺失，新增93面；但帧1/38有26退化面。逐点对照发现侧壁136点中32点六组键坐标均统一升高0.0003模型单位，正好丢失此前加厚结果。所有32点能以此偏移匹配源数据，见 `weld-side-offset.log`。

随后 `lanlao-side-weld-basis.blend` 使用源 Basis 键而非过期 `v.co` 新建顶点。独立检查侧壁136点在6组键坐标（7位小数）和骨权（6位小数）全部匹配；旧主网格键、权重和22,277面外皮几何/逐角UV签名5位小数均0缺失。新增93面在1/8/12/16/20/30/35/38帧均0退化、0非流形，局部仍有18个开放边。另一独立算法重新识别62条源侧壁与原皮肤的配对边：旧主网格25593点 Basis 按索引最大差0，焊接后62条边均确实各连接两面（`check-weld-edge.log`）。

以上是单侧局部结构证据，不证明整体口腔闭合、视觉自然、身体动作、GLB或网页兼容。实验尚存在侧面裂纹与不自然的舌头，正式网站未修改。
