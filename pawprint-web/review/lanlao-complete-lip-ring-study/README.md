# 两侧延伸的嘴缝与内壁实验

独立 Blender 副本，未接入网站。与只处理前唇十余点的实验不同，这版将切口延伸至面部两侧，并基于 35 个边界点创建连续的上下唇、向内延伸的六行网格及口腔后壁。每条网格行随对应头骨或下颌顶点权重移动，且在远离开口的脸颊区域收敛。用户希望舌头比前一长舌版短约 25%，本实验延用缩短舌头。

第一版切口与权重均过宽：正面嘴大得不自然，侧面出现裂缝（wide-*.png）。后续控制前唇开口宽度并让脸颊的口腔厚度随下颌权重归零，静态渲染中侧脸裂缝不再可见；闭嘴静态外观接近原版。当前正面仍有黑色尖角与偏塑料的舌头，侧面舌根呈细片且下颌口底不自然。加大张嘴角度仍未有效解决侧面问题。

这些是方法试验，不是可信的真实口腔建模：嘴部内壁还没有完整曲面与牙龈、舌根的解剖连接；没有检查开合连续性、动画导出、其他动作及浏览器。不可接入正式网站。脚本为本机复现草稿，按 build-shaped.py、build-shaped-inner.py 顺序执行，其中部分临时文件路径需按本机环境调整。
