  - 2026-11-08 子代理在无密钥隔离环境检查：蓝老模型加载；走/停止、坐/趴/站状态正常；离线对话和发送按钮恢复；中英法求助及告别提示均可显示。英语下取消告别保留输入、确认后清空。评委页两条离线规则示例结果正确；刻意断开及恢复本机服务后本地回复仍可用。另用本机模拟供应商验证“已配置→失败→成功”提示；不是对真实供应商的验证。无 JavaScript error，T06 修正后模型加载未再产生相关弃用警告。工作室及完整设备矩阵尚未完成，不能勾选整项。

## 第二优先：AI 实验、用户与真实生成证据

- [ ] **E01 · 冻结独立意图测试。** 由未参与调参者编写并标注中英为主、必要时法语的否定/叙述/间接/多指令及普通对话样例；先冻结再测试，保留未命中与误动作。
- [ ] **E02 · 分别测规则、在线模型和完整语音链。** 标明模型/版本、题集、语言、结果、误动作率、延迟、费用及失败恢复；语音识别需另行实测。任何付费调用先核对费用和范围。
- [ ] **E03 · 更新旧比较报告。** 核对 `public/evidence/intent-comparison.json` 与当前规则源码哈希，重跑或明确标为旧版本；小型分类器未接入网页、315 句为 AI 起草草稿，不能声称已由学生审核或正在在线学习。
- [ ] **E04 · 实际新宠生成与人工验收。** 在有照片授权且费用明确的情况下，记录上传、生成、候选模型、毛色、四足绑定、动作、失败、耗时和费用。模拟流程必须标为模拟；不承诺新宠自动获得蓝老全部动作。
- [ ] **E05 · 同意参与的用户可用性测试。** 按 `SUBMISSION-KIT.md` 先做小规模成年宠物主人访谈/任务，记录实际人数、完成率、耗时、控制感、理解程度及负面反馈；这些结果不能证明治疗作用或代表所有用户。
- [ ] **E06 · 问题和目标用户验证。** 明确项目服务失去宠物、暂时分离还是一般纪念的哪类人；用访谈与公开研究支撑需求，不将英国成人数据推到青少年或假称疗效。

## 第三优先：设计、动作与原创贡献

- [ ] **C01 · 蓝老身体动作。** 正面和侧面连续检查走/跑/摇尾/坐/趴/起身，记录脚掌、腿根、身体与尾巴问题；只接入视觉及动作回归都合格的修改。
- [ ] **C02 · 嘴部与下颌。** 现有嘴部为未接入网站的试验：完成唇缘与口腔内壁、舌根及绑定，检查闭嘴融合、开口侧面、毛发穿插和所有原动作后再决定是否上线；不要把草稿称为完成。
- [ ] **C03 · 统一页面与语言。** 核对中/英/法主要流程、失败文案、错误路径、帮助和告别说明；重点消除对行为、存储、效果及服务可用性的过度承诺。
- [ ] **C03a · 明确离线回复后的输入行为。** 当前失败回退后文本仍留在输入框，可能方便重试，也可能造成重复发送；先决定是保留还是清空，并让提示和重试行为一致，再通过实际页面复测。
- [ ] **C04 · 用户可控与退出。** 验证停止、停止语音、麦克风关闭、重置视角、取消/删除任务以及音频不重叠；清楚标记 AI 合成语音和模拟形象。
- [ ] **C05 · 学生贡献与来源表。** 由学生按真实事实填写谁提出问题、设计、编程、测试、修改和解释；单列导师、Codex、Tripo、其他预训练模型、开源库、宠物照片和其他素材。保留学生草图、记录、修改和审核证据。
- [ ] **C06 · AI 五大概念与问答。** 用项目真实数据流解释感知、表示与推理、学习、自然交互、社会影响；说明哪些来自外部预训练服务，哪些是团队程序，不虚构训练或情绪识别。学生练习解释一次真实失败与改进。
