# 双侧嘴缘切口：失败的对照试验

以 `../lanlao-side-mouth-shell-study/base.blend` 为输入，复制侧口切割至另一侧（以 y=-.035 为镜像中心），保留每侧内壁、骨骼权重和毛发形态键。双侧切割影响324个面、得到50条切边；进一步分离10个同时连接上/下唇的顶点并重建16张下脸面。Blender离线渲染闭嘴、正面张嘴、侧面张嘴。闭嘴静帧外观仍似原版，但张口时正面两侧出现明显矩形缺口，侧面露出断面；不符合自然要求，不可接网站。隐藏侧内壁后仍有相同矩形空洞，说明外脸切口边界本身不连续，单靠补口内材质解决不了。脚本是可查看的研究草稿，`lanlao-biside-split.py` 需将 /private/tmp/lanlao-biside-v1.blend 输入路径改为本目录的 `lanlao-biside-v1.blend` 后重跑。未测试全动作、UV精度或实时网页。
