# 舌体曲线独立实验

基于 `../lanlao-workflow-joined-tongue-study/base.blend` 的独立副本，将舌根延伸到口内、舌尖往下弯，尝试避免舌头呈直线细片；口底以原网格口底边界连接，不是仅贴在表面。舌体中心线长度数值积分约0.0501，与历史舌头试验线段长度0.06684的比值约0.75；这只是模型坐标内的中心线长度，不代表屏幕露出长度精确减少25%。模型、基底、构建脚本及帧12/20正侧渲染保存在本目录。

结果：正面可见短舌，但侧面仍表现为细钩状；过渡帧口缘出现明显锯齿黑线，正面仍有尖角。并未检查完整开合、拓扑和舌体/面部碰撞，也没有验证现有动作和网页导出。该结果不自然、不可接入网站。仍需与真实侧嘴开口、唇角几何和舌根共同修复。

## 嘴缘与短舌同步试验

以 lip-basis.blend 的 LipSmoothTest 原顶点形态差为基础，经逐点确认 25,319 个原有对应顶点 Basis 误差0后，迁移该形态到 preview.blend；新舌头顶点沿用本实验，不复制旧舌位移。合并模型为 combined-narrow.blend，进一步按下颌实测角度逐帧同步 SoftRoundMouth，保存 combined-synced.blend。帧8/12正面锯齿黑线比不同步版缩短，但仍明显且不自然；帧20正面是扁直开口，侧面舌尖呈细钩而嘴角近乎闭合。当前不是自然预览，也未验证全程碰撞、其他动作、GLB 或网页。
