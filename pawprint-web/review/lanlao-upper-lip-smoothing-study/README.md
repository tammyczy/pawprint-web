# 上嘴唇一圈局部平滑实验

从 `../lanlao-lip-sync-study/preview.blend` 的独立副本出发，仅选择外表面材质中 19 处上下唇同坐标匹配点的上唇，再加一圈相邻外表面，一共49个顶点，构造随张口时启用的独立形态键；最大局部高度位移为 0.003 模型单位。原有形态键数据不修改。只有上下唇同坐标但下颌权重相差超过0.2的点被视作嘴缘，以避免把内壁的错层点当外唇。

闭嘴静态画面保持原貌，8帧前唇锯齿略减，但20帧仍像横向黑缝、嘴角太尖，侧面舌头像薄片从下巴伸出，未达到自然要求。未验证全部形态键的独立运动、逐帧动态、原行走/跑跳动作、GLB 或网页。正式模型没有修改，不能当做成品。

第二次尝试通过同位口腔点共同跟随外唇，将上下唇按局部椭圆目标协调变形（19 对、95 点，最大位移约 0.00322）。正面早期稍平顺但张开仍似水平黑缝，侧面没有真实张口，舌头仍如薄片；同样未达到自然效果，不可用作成品。
