# 收窄嘴缝和连续内壁的实验

独立副本。由原模型重新切出比既有实验窄的嘴缝，建 10 个剖面点构成连续骨骼驱动内壁，添加随开合收缩的唇缘。舌长比既有长舌试验缩短约 25%。构建和渲染脚本保留；多个脚本通过 /private/tmp 中间文件按 build-narrow、connected-narrow、build-rim、morph-rim 顺序生成，不能视作生产构建。

闭嘴静帧看起来保形；正面口腔仍有尖锐不对称黑色裂口，舌面偏塑料；侧面舌头像细片、口底和舌根缺少自然连接。仅做静态图，没有连续动画、其他动作、网页运行或性能测试；不能视为自然成品，也未接入网站。

后续依据嘴缝顶点权重检查发现：一端的末端仅保留下颌侧且权重约 0.54，导致末端未合拢。对距中心 .019 至 .029 的范围使用对称平滑过渡，超出归零，正面不对称尖角明显减轻，效果见 round-weights 文件。把开口角由 0.16 调至 0.20 弧度后，正面仍相对整齐，但侧面仍像舌片从几乎闭合的下巴伸出，并没有可信的口腔与舌根。round-open-angle 也未通过自然度验收。两版仅 Blender 静态渲染，未经运动、导出或网页验证。
