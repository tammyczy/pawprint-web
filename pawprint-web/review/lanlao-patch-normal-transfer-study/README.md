# 补片法线转移独立实验

将 v6 模型口鼻补片上 264 个角法线，按最近原脸三角形及重心系数插值原有逐角法线，保持其余网格和模型不动。检查各采样点到原脸表面最近距离最大约 1.08e-7 模型单位；渲染在同样相机灯光下比较。

闭嘴正面下口鼻区域 x270–410/y355–420，RGB绝对差均值相对原脸由 v6 6.412/255 降至法线转移后4.698/255；单像素任一通道差大于20比例由6.1%降至0.4%。这是5采样静态渲染与选定局部的筛查，无法证明视觉一致，也不证明动态或网页导出正确。闭嘴线变轻，但张开正面仍是黑口且缺少自然的舌根，侧面仍像细线，离自然效果很远。

`preview.blend` 是独立快照，构建脚本读取 `/private/tmp/lanlao-patch-v6.blend`，输入需要改为持久化副本；此外临时加载原文件的 object 用作法线来源。未验证 GLB、骨骼动画、变形过程中法线、网页或用户设备；不用于正式网站。
