# 35 点嘴环与短舌组合实验

独立实验，未修改网站模型。将舌头纵向跨度缩短 25%，与 35 点、六层口腔独立模型组合，正侧及闭嘴静帧见本目录。闭嘴正面近似原貌，但侧面舌头仍像从下巴穿出的薄片；口腔的下唇/口底与舌根尚不连续，不能认为自然。

进一步观察实际变形的模型点：帧 20 中央上唇 z≈.579，下唇 z≈.556；先前舌根中心 z≈.586，在开口上沿之上。尝试沿网格 Z 轴下移 0.020，模型结果却是正面舌面与口底断开、侧面从下巴下方出现，未达到舌根接合，因此保留为 lower-root-failed.blend 与截图，不采用。原因是现有舌头对象的骨骼局部变换及脸部外表遮挡不能仅凭坐标偏移解决，需要重建或改切完整口底拓扑并检查运动。
