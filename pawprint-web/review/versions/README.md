# 三个累计优化阶段的源码快照

本目录是**由审查完成的源码重建的三个累计阶段**，用于检查功能分层和继续开发，不是三次历史发布。V1 保留原 parser；V2 加入新版 parser／实验；V3 加入评委证据页面与提交文档。共享目录的其他并发编辑也被保留，不应把快照差异当成作者身份或严格时间历史的证明。

| 压缩包 | 内容 | 桌面预评 |
|---|---|---:|
| `v1-source.zip` | 请求、表单、任务状态、预算恢复、前端生命周期修复，保留原始本地 parser | 66/100 |
| `v2-source.zip` | V1＋保守本地 parser、68 条开发／对抗样例、可复现 JSON | 71/100 |
| `v3-source.zip` | V2＋`judge.html`、逐项审查、英文提交及答辩草稿 | 76/100 |

每个包内 `version.json` 列出 SHA-256。包内没有真实 `.env`、`.data`、node_modules、dist，也不重复大型公开模型／图片／声音。

要独立运行某个阶段：在**新目录**解压该包，把原项目 `public` 中模型／声音／图片复制过去（V2/V3 已有的 `public/evidence` 应保留），使用包内 `.env.example` 建立新的本机配置，再 `npm install`、`npm test`、`npm run build`。不要覆盖当前项目或把真实用户 `.data` 复制给评委。V1 没有 evaluate 或 judge 页面；V2 没有 judge 页面。只有最终 V3 在本次做过完整 34 项测试及浏览器检查；不把重建包写成独立通过三次端到端验收。

源码原始备份在上一级 `baseline-source.zip`；复建脚本是 `create-snapshots.ps1`。脚本遇到既有快照会停止，避免覆盖历史检查点。
