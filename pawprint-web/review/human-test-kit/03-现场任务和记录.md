# 现场体验任务（草稿）

## 参加前由负责人说明

“这是 Pawprint 的数字宠物原型。它是模拟，不代表真实宠物的思想，也不是心理治疗。我们测试界面和操作，不测试你的能力。参加自愿，你可以跳过任何步骤、暂停或退出，不用解释原因。默认不录音、不录像、不公开引用。请只使用虚构句子，不输入私人信息。若你选择使用在线对话或语音，负责人会在你同意前解释数据会发给哪家服务，以及项目所知的保留边界。”

负责人先填写并与参与者确认：年龄已满 18 岁（自愿自述即可，不收身份证明）___；负责人／联系方式 ___；可访问原始数据的人 ___；保存期限 ___；退出与可撤回期限 ___；是否同意仅作本次测试笔记 ___。录音、截图、公开引用、将虚构测试句发送到 OpenAI、使用浏览器语音服务分别单独询问并记录；任何一项拒绝，不影响其他未依赖它的步骤。此前已送达第三方或已公开、无法定位的副本，不能承诺一定撤回。

## 任务（只使用蓝老示范和虚构文本）

不要告诉参与者按钮的位置；每项记录独立完成、提示后完成、未完成、主动跳过或未开始，以及技术故障。计时从读完任务到明确完成；不把提示后完成算成独立完成。

1. **观看与控制**：找到蓝老，尝试自主选择观看角度并停止当前互动。观察能否找到操作、是否可结束，不强迫触摸或聊天。
2. **文字动作**：使用预先冻结的虚构指令要求一个动作，再用自己的话让它停止。记录起始状态、输入、最终动作和是否产生其他动作；若服务失败标错误，不算用户或模型正确。
3. **回忆卡**：输入负责人提供的虚构素材（未获同意前不发送 AI），找到下载原文和清空入口；如果参与者另行同意发送虚构内容，再试 AI 整理并让其指出草稿与原文的区别。只记录操作与自愿反馈，不要求写真实记忆。
4. **帮助与理解**：找到真人支持资源，问“这个形象的回复代表真实宠物的想法吗？”；只记录参与者自愿回答及是否理解这是模拟。
5. **声音与麦克风（可选）**：先解释浏览器可能将语音送给供应商，再单独获得权限；拒绝时使用文字/按钮替代。说事先同意的虚构句子，记录口述原文、浏览器识别文本、最终动作、延迟与设备。不要因一个真实宠物主人的口音或年龄作推断。无需录音就不录音。

如果想比较静态照片与互动版本，必须先制作和核验同等进入、退出、素材和显示条件的静态基线；否则不能宣称已完成 A/B 对照。
