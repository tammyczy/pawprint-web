# 独立标注说明（草稿）

请在不知道作者意图、另一位标注者选择、程序规则或模型结果的情况下独立完成。仅以输入文字和明确给出的开始状态判断；不知道时选择 `ambiguous` 并说明。完成各自标注后才讨论，保留每人最初的结果及所有分歧。

动作代码：`none` 不发出新动作；`come` 走近；`home` 回到起点；`walk` 走；`run` 跑；`wag` 摇尾；`jump` 跳；`stop` 停止当前动作。一次可填多个可接受动作，用 `|` 分隔，例如 `none|stop`。无法判断时标 `ambiguous`，不把猜测当标准答案。

请特别注意：

1. 看清动作是谁要做的，叙述、引用、建议、条件和对其他人的话不自动等于给宠物的命令。
2. 判断否定的作用范围和起始状态。“不开始跑”与“停止正在跑”不一定相同；仅在上下文支持时将 `stop` 当成合适动作。
3. 对多动作顺序，注明完整意图及系统如果只做一个动作遗漏了什么。若评测规则采用停止优先，只能说符合该规则，不能声称完成全部请求。
4. 只对清楚的语义赋值；原文可有不止一种合理理解。不使用护栏或模型输出来决定标签。

在你的 `rater-template.csv` 中填个人代号、每个 `case_id` 的可接受动作或 `ambiguous`、原因和置信度（高／中／低）。这些只是研究记录，不收姓名、联系方式或其他个人资料。
