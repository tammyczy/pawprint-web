# 蓝老跑步响应、步态和腿根蒙皮修复

日期：2026-11-09。已更新本机演示站点：<http://127.0.0.1:8788/app.html?lang=zh>。

## 实际发现和修改

1. **“过来”后点跑步有时没有反应**：过来的目标靠近镜头，处于原来的全身可见活动范围之外。原路径规划拒绝从这里起跑，随后静默停止，但界面已经显示正在奔跑。现在先规划可行路线，必要时平滑拉远镜头留出空间，再启动动作；停止或新指令会取消待启动动作。连续点跑步会延续运动并规划后续路线。
2. **跑起来像高抬腿的小跑**：增加疾跑收腿阶段后脚向腹部下方的落点，让后肢完成收拢、着地、向后蹬伸。降低过高的抬脚幅度，延长摆腿加减速段，保留落地脚在世界坐标中的接触点。加入疾跑切换迟滞，避免临界速度反复切换步态。
3. **转弯时碎步、颈肩像脱节**：规划器优先更宽的弯道，调整曲率限速，让普通转弯保持小跑节奏。头部随胸肩一起下沉、前伸，避免身体伏低而头留在站姿高度。支撑腿接近伸直极限时，胸肩与髋部有小幅顺应下沉，减轻膝关节突然绷直。
4. **腿根毛纹拉伸**：生成 `lanlao-rig-motion-refined.glb`，在肩部、腿根和髋部做有边界约束的权重优化，并对 UV 接缝附近的权重保持一致。原来的 `lanlao-rig-hip-refined.glb` 保留。新文件只修改现有 WEIGHTS_0 数据；网格、UV、纹理、材质、骨骼绑定矩阵、形变目标和动画保持不变。

## 迭代与验证

- 第一版权重基于跑步和姿态采样；第二版加入后腿收拢后的新动作与起跑阶段；最终版增加坐下、趴下和起身约束。最终训练集包含 97 个姿态，比较了 20/40/80/160/240 次优化的候选结果。
- 在 Blender 中按网页实际使用的四权重、线性蒙皮方式复核收腿和蹬伸姿态。`lanlao-motion-review.blend` 保留最终检查场景，`before-*.png` 与 `after-*.png` 保存对照。
- 独立于权重优化采样的运动检查，使用不同速度、转弯变化和取样时刻；新旧蒙皮使用完全相同的新版动作，避免把动作改进混成权重收益。
- 全套 Node 测试 **202/202 通过**，无跳过；Vite 构建通过。包括 36 组不同画幅、相机旋转和缩放的近处起跑规划，以及脚接地、步态连续性、制动、起身、颈部长度、后腿落点和蒙皮形变检查。
- 最终构建的真实网页按钮操作已检查：过来→跑步→停下；趴下→跑步→停下；连续多次跑步→停下。已观察到对应移动和恢复站姿，本次浏览器检查无 warning/error。此结论针对本次实际检查，不代表所有浏览器和设备都已测试。

## 蒙皮独立采样结果

“最大边长比”是变形后网格边长相对原始边长的最大比值；“超过 2 的边数”是每个动作采样中最差一帧的数量。数值用于发现局部拉伸，不是自然程度或视觉质量分数。

| 动作 | 原权重最大边长比 | 新权重最大边长比 | 原超过 2 的边数 | 新超过 2 的边数 |
| --- | ---: | ---: | ---: | ---: |
| 疾跑 | 5.109 | 3.714 | 178 | 146 |
| 转弯 | 4.760 | 3.857 | 252 | 230 |
| 步态切换 | 4.864 | 4.212 | 218 | 158 |
| 制动 | 5.109 | 3.714 | 178 | 146 |
| 坐下 | 2.472 | 2.328 | 316 | 50 |
| 趴下 | 3.488 | 3.565 | 522 | 360 |

疾跑和制动的峰值拉伸约降低 27%，转弯约降低 19%。趴下的严重拉伸边数量减少，但最差单边比值约增加 2.2%；不能声称每个区域都改善。近看腿根仍有原始毛纹和几何折痕，进一步消除需要局部拓扑或姿态修正形变，不应只靠扩大权重平滑。
