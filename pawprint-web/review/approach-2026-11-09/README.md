## 行为

- 从当前位置朝镜头所在方向走近；先以有脚步支撑的转身对准镜头，再前进。停稳时继续校正朝向，保证正脸朝向用户。
- 不再重复走向固定的 `.85` 半径目标。已经靠近时，再次“过来”会安排约 `.22` 模型单位的前进一步，受最前方构图边界限制。
- 接近最前方后停稳、抬头与轻摇尾回应。通过真实根节点移动、接地步态和透视表现前进，模型缩放不变。
- 镜头视线平滑跟随胸口。如果先前跑步拉远了镜头，走近时会随实际前进进度回收构图。限制舞台前方位置，避免反复“跑步→过来”把活动区域和镜头越推越远。
- 前景隐藏脚边的拖动提示和重复说明，旁边控制区仍保留 AI 模拟说明，恢复视角按钮继续可用。
- 到达后重新计时等待，避免从远处走来花费较长时间、刚到眼前又立刻触发自主活动。近景之后的跑步或自主离开会先恢复适合活动的视野。
