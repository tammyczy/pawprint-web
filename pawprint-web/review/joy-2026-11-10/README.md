# 蓝老：摇尾、身体松弛感与眼神 — 2026-11-10

用户希望摇尾幅度更大、整个身体更轻快，并改善显得忧郁、眼神无活力的观感。

## 研究转化

- [ASPCApro：犬的身体语言](https://www.aspcapro.org/resource/canine-body-language-tips)：宽松的左右摇尾要结合放松、轻快的身体和柔和眼神来理解；紧绷、高位而快速的小幅摇尾并不等于开心。卷尾犬应保留其自然的尾部姿态。实现因此保留蓝老卷尾形状与原节奏，增加尾根和尾梢摆幅，让髋部带动身体、肩膀轻微反向平衡。
- [Leonetti 等，2024，Biology Letters](https://pmc.ncbi.nlm.nih.gov/articles/PMC10792393/)：摇尾存在个体和品种差异，频率、幅度、尾部位置等需要分开考虑，摇尾也与多种唤醒状态有关。本文没有提供适用于蓝老的精确动画角度，本轮数值是针对现有模型的动画调校，不是生物学测量。
- [RSPCA：理解狗狗身体语言](https://www.rspca.org.uk/en/adviceandwelfare/pets/dogs/behaviour/understanding)：愉快、放松的状态综合体现于身体、耳位、眼睛和嘴部。闭嘴本身不能单独判定情绪。

## 发现与修改

1. 原摇尾动作的尾根相对静止姿势最大旋转约 25.3°，身体跟随较小。新版尾根旋转放大 1.75 倍、尾梢 1.5 倍；与原动画共用相位及淡入淡出，没有另加不相关的尾部振荡器。
2. 放大髋部侧摆，用肩膀轻微反向平衡和腿部屈伸吸收变化。保持脚掌原有接触位置，保留原动画很小的竖直变化。
3. 原表情控制器在摇尾模式直接退出。新版允许头和耳朵继续关注观看者，受角度上限约束；尾巴继续由摇尾控制器独立负责。
4. 站立时稍微抬头、温和关注观看者，缩短看一眼周围或看向人的间隔；被抚摸和问候时尾部反馈略增。休息时仍保持安静，不会一直盯着观看者。
5. 眼周深色毛发做局部、低强度提亮，黑色眼部使用较低粗糙度，毛发继续保持哑光。增加很弱的正面补光。反光随真实场景灯光和角度变化；眨眼时减弱眼部光泽。
6. 中途停止摇尾时，先捕获放大后的尾部和身体姿势，再过渡回站立，避免回到旧尾部角度后才开始收尾。

迭代记录：第一轮放大动作、恢复摇尾时的关注反应；第二轮近看头部，微调眼部粗糙度及眼周色调、加入弱补光；随后补充中途停止的有效姿势捕获。头部网格、嘴部和蒙皮资产未更换。

## 范围与限制

当前模型没有独立眼球、眉毛或嘴角的表情绑定。本轮改善的是头耳姿态、关注节奏、眼周材质和灯光，不应描述成已经重做面部肌肉或实现自然张嘴笑。视觉上的“亲近、开心”仍需用户判断；自动测试只能确认动作约束和连续性，不能替代这种判断。原模型局部毛纹和腿根蒙皮限制仍然存在。
