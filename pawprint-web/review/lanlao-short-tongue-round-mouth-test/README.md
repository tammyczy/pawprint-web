# 对称嘴部与短舌实验

在独立对称嘴部几何上，舌头相对原长舌版 Z 跨度减少 25%，根部向口内延伸，厚度适度增加，并使用口内收拢形态键。闭嘴正面近似原样；正面开口可见舌头与内壁，但侧面仍仅见薄舌伸出，嘴部没有真实的侧向开口，斜面嘴角亦不自然。将舌根进一步推入口底的试验导致舌面被下颌遮盖、正面断层，未采用；加厚和弯曲造成钩状，未采用。该版本并非用户要求的自然结果，未做动态、网页导出、动作或设备验证。

独立 Blender 快照 preview.blend 与各角度静帧在本目录，build.py 依赖 /private/tmp/lanlao-round-open-angle.blend，需保留或修改输入路径。
