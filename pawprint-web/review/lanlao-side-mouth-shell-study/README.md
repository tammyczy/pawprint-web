# 侧嘴外壳切分与跨口面诊断

此独立实验未接入网站，不是自然预览。射线确认侧视口中 x=210–260、y=378–395 的遮挡多数来自身体网格原皮毛材质，而非口腔本体；单靠移动舌头不能打开遮挡外壳。旧嘴缘纠正将侧唇距离从约0.009–0.016压至约0；基于 x 坐标衰减纠正后数值恢复，但外脸仍遮挡，视觉不自然。

在基础副本中对侧口的167个脸面进行局部切分，31对切边，103个下唇附近点重新绑定，建立随动画变形的侧内壁。侧面出现真正开口，但有严重矩形断面、前面不对称，不能使用。独立检查发现部分浅色竖条由原外皮面20529等跨越嘴口产生：面20529里有三个上脸顶点不受下颌驱动，同面一个嘴线顶点以0.72下颌权重下降约0.0185。

于是将5个同时连接上下面的嘴缝顶点复制，9个下脸面依面方向重建，复制 UV、形态键、下颌与头骨权重；部分遮挡像素射线由旧外皮面转为口腔面，闭嘴静态外观保留。但张嘴侧面仍有黑色矩形裂纹、正面不自然，未达到用户要求。旁证来自独立审查：原网格形态键坐标签名在五位小数精度零缺失，原权重签名零缺失，未验证UV数值。侧内壁仍有80条开放边、1条非流形边，闭嘴帧26个退化面，动态和其他动作未验证。

复现顺序：cut-side.py 读取本目录 base.blend，先输出 /private/tmp/lanlao-side-surgery-sync.blend；split-mixed.py 读取该临时文件并输出 /private/tmp/lanlao-split-mixed.blend。脚本包含临时路径，须按环境调整。raycast-before/after.log 和 offending-face.log 为诊断记录，PNG 为实验帧，不当成成品。

补充 clean/thickness：修复重合口角四边形重复顶点后，独立审查指出非流形边由1降到0，6个现有形态键坐标签名保留；但侧内壁仍80开放边，闭嘴26退化面。thickness.blend 仅在原内壁面下方32点（非外脸边）对所有形态键 z 减0.0003，实验目的验证闭嘴厚度；视觉和动态复核尚未完成，非成品。
