# 动作护栏三轮交叉审查

本集由 Codex 测试子代理编写、使用虚构文字与合成模型动作，测试纯函数而非真实模型、浏览器、动画或真人用户。每轮先冻结输入并记录哈希，再运行；发现问题后该轮变成开发集。子代理继承项目上下文，不能声称为独立人类盲测。测试是否触发动作依赖给定 modelAction；给动作是为了探测护栏，不能推断真实模型会给同样动作。

## 第一轮：基线与标注复核

- 冻结集 `round1.json` SHA-256 `e904abc7a8c8edb9db2c2ce07bded226413476ccab490799b52fa8f466554a4f`。`round1-results.json` 记录每条给定模型动作、识别及最终动作，以及被测源码哈希。
- 批评性复核发现 `r1-zh-08` 的 allowed 过于保守：用户说“别跑，过来陪我”时 `come` 本身合理，实际结果不能作为明显错误。原始标签保留，人工复核时单列争议，不伪装为无歧义错误。
- 其他 7 条未符合预标记，其中英文／法文停止音乐、停止思考和 walk through options 等将非身体指令误认为宠物动作；中文负面和英文多指令中保守暂停、明确停止的语义需讨论，英文和法文的部分明确请求被拒。正在与开发代理讨论，应复测常见变体并确认对语境的影响。
- 36 条不是代表性数据，极少数标签与默认状态相关，不报告准确率或安全保证。

## 第二轮：第一轮修复后的新反例

- `round2.json` 在第一轮修复前冻结，SHA-256 `5288aff2ef2ae71d80f28afdd118c992e822abb5bb36cebfe167053dd5699bd6`；`round2-results.json` 记录逐题与被测源码哈希。其 48 条是不同表达的模拟模型动作，不代表独立人类或真实模型。
- 第一次运行暴露跳过歌曲被识别为 jump、用户表示还未让狗动却触发 run、“不要运行软件”被解释为 stop、明确中文“不要动”被遗漏、法语明确散步邀请被拒；都已提供给实现者，因此第二轮之后成为开发集。
- 有的项目选择单动作或对风险语句保守暂停；一个语句可有多种合理策略。包括否定分句和按时间先后命令的情况应记录上下文与操作状态，不能仅用这个合成集宣布安全或概括总体效果。

第二轮首次发现的 5 条现已由实现代理根据反馈修复，`round2-after.json` 保存其所在版本的 48 条开发题的重放；这是针对同一批题调参后的结果，不是独立准确率。

## 第三轮：未提供给开发者的新样例

- `round3.json` 在第二轮修复结果运行前冻结，SHA-256 `5d5ff673273243c313a74c66be8fc05455801075050d8d4ba18f439b941a5716`。45 条中英法合成文本与给定模拟模型动作，经 NFKC、忽略大小写和非字母数字后，与已读的此前数据没有精确重复；未做语义近重。题目没有在本次执行前提供给实现代理，但作者参与前两轮并知晓产品及背景，因此仅是 AI 代理生成的探索性未见样例，不是人类盲测或用户分布。
- `round3-results.json` 保留每条结果和被测源代码指纹。按预标记规则 12/45 不一致；其中 4 条模拟模型误返动作时未被拦截，另外 8 条是明显请求、停止或单动作顺序约定未达预标记。具体标签可由两位独立人类评审后讨论，尤其对模糊的停止语义和多动作顺序；此小样本不推算真实发生率。
- 本轮结果发现可行动的实质问题，主代理决定基于问题类别进行第三轮修复，故这 45 条属于开发集，不作为调参后的独立成绩。另准备新的小规模未向实现代理透露的样例，在修复冻结后单次评估；也不是人类盲测。
