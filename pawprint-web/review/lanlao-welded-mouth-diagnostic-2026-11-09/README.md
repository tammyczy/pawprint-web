# 嘴缘共享顶点实验（诊断，未通过）

2026-11-09。原有内壁的构建脚本把不止一条前后交叠的边界点按横坐标排序，容易把不相邻点连接；单纯连接独立曲面不能保证嘴唇与脸部一致。此试验从 `lanlao-complete-lip-ring-study/preview.blend` 复制，删除其独立口腔网格，按原切口的实际边配对，仅选前部且有下颌权重的 11 对边，复用原网格顶点构建向内的三层连接面，复制下颌和头骨权重，新增 30 顶点、33 个面。静态结构检查结果：22/22 选中原边均连到新增面；三组已有形态键存在且顶点数量一致。未验证所有顶点属性、法线、形态键位移及动态闭合。

视觉不通过：相比原闭嘴，闭嘴时前面仍出现浅色横线，侧面张口仍不自然、舌根没有连通。较宽的 33 对边版本出现侧脸裂缝；只用 11 对前部边可去掉大范围侧脸裂缝，却无法解决侧面张口。边连通不证明连续面或嘴型正确，也不证明已焊接到舌头或其他面。该试验未运行所有动作、动画、导出或网页验证，严禁直接替换正式网站模型。

脚本位于 build.py；本地临时输出为 /private/tmp/lanlao-welded-front.blend，可按实际目录修改。预览 blend 和三张渲染在本目录。Blender 4.5.15。建议后续先重拓扑有真实嘴角路径的外表面与多层内口面，保留 UV/法线、形态键和骨骼绑定，再处理舌根和连续运动；不要单独复制填面当成解剖结构。

补充逐顶点检查：原有 23,603 个顶点的 Basis、Original_Coat_Sway、Original_Coat_Rebound 中坐标分别逐项不变；30 个新点在三个形态键中完全相同，没有复制源嘴缘顶点的形态键位移，因此动态状态下接缝风险仍然存在。已存 check-shape-keys.py（临时路径需按环境调整）。这并不解释所有闭嘴浅色接缝，法线和内部面的可见位置还需单独检查。
