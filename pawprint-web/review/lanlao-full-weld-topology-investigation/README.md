# 前嘴完整边链焊接实验（未达自然效果）

实验建立在 `review/lanlao-complete-lip-ring-study/preview.blend` 的副本上。通过识别嘴部前侧连通分量，扩展此前仅覆盖11对切口边的共享顶点内壁到完整25对切口边，创建75个内壁面，并复制源点三个形态键偏移。25对50条口缘边与新增内壁连接；硬边隔离平滑法线。闭嘴静态无明显新增接缝，但侧面几乎不开口、舌头仍像从下巴穿出，不符合真实表现。

更详细拓扑检查：初版新面含54条边界、25个闭合时退化面，不能称为完全连续的口腔。按坐标、权重和所有形态键匹配合并新点后降为42边界、9退化面；进一步合并同样匹配的原嘴部点导致16条非流形边，不能使用。仅选择确实有相对下颌变形的11对活动口缘，再合并等价顶点时取得6条边界、0条非流形边；经过求值的张口过渡帧8、12、16、20、30、35无退化内壁面，闭嘴帧1与38各有2个退化面。不代表完整闭环、UV可靠、舌根有效、视觉自然或原动作保持。

另以每边口腔候选调整前方宽嘴区域的权重：正面缩窄但形成横向尖细裂缝，侧面仍不自然（`frontwidth-open.png`、`frontwidth-side.png`）。因此没有候选达标、没有修改网站模型。脚本引用 /private/tmp 输入，需据保存的独立副本修改路径才能重建；未做现有动画组合、GLB 导出、设备或网页测试。
