# 局部口周拓扑替换实验（未通过）

独立模型，以未切割原始 `../lanlao-hip-posture-review.blend` 为源。选择原鼻口局部 87 张面，真实替换为以实际33边界组成的外圈及人工构造的口唇、口腔后壁；边界邻接闭环后按真实次序连接。新增颌骨用于演示闭嘴/张嘴，不包含短舌；所有代码仅写临时目录。

版本1和2：直接从原有 UV 图集逐点采样，在闭嘴和张嘴都产生严重跨 UV 岛色块、鼻口皱裂，完全失败。

版本3和4：从原始表面投影烘焙连续局部毛色贴图，修复显著跨岛碎色；正面闭嘴仍有横线，贴图只是 base color，尚未投影原法线和粗糙度贴图，且本地重拓扑会改变局部形状。版本4加入有后壁的口腔、逐渐收敛的下唇，张口变成小 U 形，但侧面几乎没有口腔打开，也没有舌头。

版本5：加入仅张口时作用的侧嘴形态，侧面可以打开但形成不自然尖角；闭嘴仍有线，无法验收。局部补片真实是重做网格，不是现场网站模型；没有舌体、没有完整嘴唇/口底连续性验证，未验证UV无拉伸/闭环/连续动画、旧动作或 GLB/网页。当前不自然，不可上线或用作自然预览。

初步只读审计：版本1和2的原始 23,504 点 Basis、两个毛发表情及全部骨骼权重签名（5位小数）零缺失；切除范围外原面及逐角UV签名0缺失。四个原 Walk/Run/Wag/Jump 曲线结构仍在，但基底的当前活动 `Puppy_RigAction` 被新的 `Puppy_RigAction.001` 取代；未经实际动作数值/外观/叠加验证。V4/V5需独立核验，不能用旧版代替。

版本6：尝试把88个新增前唇附近顶点压缩以解决闭嘴缝（使用形态键），另加单独绑定颌骨的短舌。闭嘴仍有细线，舌未与口底共享顶点，前视露出少量方形舌、侧面像细线，视觉失败。v6 独立射线抽样鼻下742点均命中外毛色补片；同一区域v4曾命中口腔，说明封闭缺口但仍存在受光折痕。纯色受光有线、发光无，表明不单是贴图颜色；这是静态筛查，不能确定唯一成因。

版本7：替换5张口底三角面，沿7个实际边界点生成四圈舌体并与口底共享边，构造开合形态键。渲染中正面只露少量粉色且被横条遮挡，侧面舌仍像细线；闭嘴仍可见细线，不自然。未做完整拓扑或动画检查。

版本8：以原始网格射线插值的表面法线给补片264个角设置自定义法线；同光源渲染闭嘴线仍明显，无法把折痕简单归因为补片法线未转移。未验证逐帧、低性能或网页。上述版本均是独立失败实验，不可作自然预览或接入。


版本9：保留 v7 舌根与口底的7个共享边界顶点，针对正面舌体横向被下唇盖住的证据，将舌中段向前弯。正面像素 x=330–345/y=405 的射线从 v7 的 Locally projected muzzle 改为 v9 的 Connected tongue pink，表明抽查处遮挡改善；正面仍只露出小粉点，侧面仍像细线，不自然。

版本10：舌中心线进一步下垂，并应用原脸最近点插值法线；侧向射线在舌根高度约 z=.558–.577 命中更靠外的毛皮补片（y≈−.057 至 −.09），仅下方z≈.549–.554可见舌面，解释侧面只见细线：主要是外脸挡住侧口，而非单独舌体厚度。渲染仍有闭嘴折线、舌面横折、侧面没有自然口腔；完整穿模/连续动作、嘴部 UV、原动作、GLB和网页均未验证。

`v4.blend`为v9/v10共同输入，`v10-droop.blend`为v10法线转移输入，相关构建与射线脚本、日志及静帧均已保存在本目录。构建脚本不会覆盖归档模型；路径含本机项目绝对路径。


版本11：在 v10 基础上转移 v5 的侧嘴形态，前 23637 个基形顶点逐项坐标一致（误差0）；张口侧面仍呈下唇尖刺、舌头细线，正面仍如小粉点，闭嘴仍有横线，远未自然。未经连续帧、碰撞、GLB或网页验证。

独立动作数据核验发现：v10 经引入参考模型转移法线时带入重复的 Walk/Run/Wag/Jump 数据块，原活动 Puppy_RigAction 为零用户数据，当前活动动作仅含下颌曲线。名称存在不能证明原动作保留或正确播放；必须确保原动作持久保存及实际叠加回归才能考虑集成。
