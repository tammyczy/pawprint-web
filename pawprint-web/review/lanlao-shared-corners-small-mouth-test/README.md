# 原脸小口缝及共享口角实验

在未切开的 `lanlao-hip-posture-review.blend` 基础上仅分开前嘴真实连通的12条切边，两端安全合并2组等价顶点；对张开的12对唇缘边生成直接连接外脸的34个内壁面，三组原有毛发形态键的新增顶点相对源点位移误差0。匹配坐标、权重和形态键后合并6个等价点，内壁34面含6条边界、0条非流形边、闭嘴10个退化面；不可称为完整闭环。张嘴帧法线朝向修正；需要进一步检查所有帧和材质UV。

闭嘴静态渲染保留原外观，小口缝消除贯穿脸颊的横线，但正面仍尖锐黑三角、侧面几乎没有开口。依据帧20上下唇实际间距制作椭圆下唇修正后没有明显改善，见 round-front-open.png。舌头仍旧实验舌，未与内壁物理连接。两个口角的共享顶点/皮肤动态连续性、嘴部内壁缺口、真实口角、舌根与口底仍未全部解决。无原有走跑叠加、动画连续帧、网页导出或设备测试，不可接入正式网站。

脚本来自本机执行，次序 build-cut, build-inner, weld-equivalent, orient；多个中间文件依赖 /private/tmp，须自行调整路径。保留独立 blend 与渲染，原始网站未修改。

补充静态坐标审计：将原始脸 `lanlao-hip-posture-review.blend` 的 23,504 个顶点以 Basis、Original_Coat_Sway、Original_Coat_Rebound 三组坐标签名（六位小数）组成多重集合，新模型能找到全部对应签名（缺失 0）。这说明坐标记录得以保留，不证明原有顶点索引、三维视觉、UV、权重或动画正确；对新增分割点的三组形态键仍需动态检查。

非嘴部 UV 只读审计：在原模型所选的17,528个切割范围以外的多边形中，按顶点坐标与原UV逐面匹配，候选模型缺失0（各值四舍五入至5位小数）。这不能证明切割区或新增内壁UV正确，也不能证明动作和渲染在所有姿态保持。
