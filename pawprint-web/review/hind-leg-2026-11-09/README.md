# 后腿步态与换速检查 — 2026-11-09

用户观察：跑步时后腿怪，像同侧腿一起走。本轮重点修正落地节奏、换速同步和收腿时的关节连续性。

## 诊断

稳定小跑的原始目标本来就是对角配合。问题主要发生在小跑与疾跑切换时：

1. 原先右后脚的落地相位从 0 插值到 0.52，会穿过左后脚的相位；两条后腿短暂合拍。
2. 躯干先切换到新步态，四只脚各自受另一套变化限速控制，落地节奏仍停留在旧步态。身体与脚步不同步。
3. 修正时间关系后，连续路径检查又暴露了后腿接近完全伸直时的膝部快速折返。

因此不能把问题笼统描述成“整段都是同侧步态”。记录中稳定小跑没有持续同侧配对，换速阶段确有后腿合拍和对角配合滞后。

## 参考依据

- [Catavitello et al., 2015, PLOS ONE](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0133936)：犬的小跑有对角肢配合，疾跑为非对称步态；前后肢关节运动也并非简单复制。
- [Walter & Carrier, 2007, Journal of Experimental Biology](https://carrier.biology.utah.edu/Dave%27s%20PDF/Walter%20galloping%20ground%20forces.pdf)：旋转疾跑存在先后发生的左右后肢接触，以及收拢、伸展两类腾空阶段。该研究的犬体型和高速条件与蓝老不同，本项目只参考接触顺序和协调原则，不把论文速度直接套给模型。
- [Afelt et al., 1983, Acta Neurobiologiae Experimentalis](https://ane.pl/index.php/ane/article/download/646/646/668)：犬的换步涉及肢体接触时间的重新分配，不能只改变动画播放速度。

## 实现与迭代

- 新增 `src/lanlao-gait-timing.js`，将步态权重与脚掌相位放进共同的连续时间关系。右后脚的走路/小跑落地点表示为下一周期，避免插值穿过左后脚。
- 四只脚与身体使用同一个受限的步态切换进度；保留支撑脚的世界坐标锚点。
- 左右后腿在疾跑时先后落地，收腿目标略有差别。根据加速/减速趋势提前准备下一步态。
- 后腿达到完全伸直前允许髋部适度下沉，减轻膝部突然伸直再收回。
- 对比过不同切换限速；较快候选仍有关节突变，较慢候选使收腿赶不上移动速度。最终使用共同相位预算 0.45，结合短时速度预估和后肢伸展余量。

本轮未重做模型网格、贴图或蒙皮资产；采用现有 `lanlao-rig-motion-refined.glb`。

蒙皮回归说明：新步态下，旧髋部权重与现有细化权重都使用同一套姿势比较。原先要求“超过 2 倍拉伸的边减少 5%”，调整为数量必须减少，同时新增连续超限量 `sum(max(edgeRatio - 2, 0)^2)` 至少减少 30%；最大拉伸至少降低 10% 的要求保留。二值计数无法区分刚超过 2 倍和达到 4 倍的边。新疾跑样本的数量是 152 → 148，连续超限量约 170.06 → 67.96。这里比较的是历史与现有蒙皮资产，不能把其改善全算作本轮修改。

限制：模型仍是程序化动画。通过接触顺序和连续性检查不代表每个动作都达到真实录像的自然程度；髋部体积和局部毛纹在极端姿势下仍受当前模型蒙皮限制。
