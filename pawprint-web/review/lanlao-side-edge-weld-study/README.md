# 侧嘴边缘焊接与连接面实验

独立副本；绝非自然预览。基于已产生真实侧口但有矩形裂纹的 side-thickness.blend，核对了侧壁外缘。136 个侧内壁点中，68 个与原脸位置、全部6组形态键位移和权重匹配，另外68个为新内壁点；利用原脸边邻接关系为62条侧壁外缘各找到唯一原边，无冲突。将侧内壁实际与原脸共用顶点后，侧壁局部开放边 80→18、非流形0；8个抽样帧新增93面0退化。独立审计报告见 ../lanlao-side-mouth-independent-audit/README.md；原脸各形态键、权重和22277个外皮面的UV/几何签名在五位小数下未缺失，仅证明指定静态范围，不证明动画及整网格质量。

分离8个上下脸混合顶点、同时让下唇及部分口腔面跟随副本后，局部开放边86→114，其中多数是几何重复的 UV/切边。按坐标、骨骼权重与6形态键签名严格核对，仅焊合签名完全一致、且在分离前不存在的8对新边，局部开放边114→98，非流形0。其余不同权重配对不能简单焊合，否则上下嘴唇失去相对运动。

对其中4个皮肤-皮肤不同权重的裂边建立共享顶点皮肤连接面，并继承相邻面UV，局部开放边98→91，非流形0。但闭嘴图新增黑线，张口正面不对称、侧面仍有矩形断面；连接面闭嘴可能退化，未做动态/UV完整验证。失败模型保留用于诊断，不用于网站。具体对照见 PNG 与 signatures.log/classification.log。
