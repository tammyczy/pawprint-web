# 基于实际边连接的口腔实验

依据 `lanlao-complete-lip-ring-study` 的本地 Blender 实验副本，按网格边邻接重建口内连接；旧脚本只按 y 排列 35 个切口点，邻接关系显示它们实际属于互不连接的 26 点前嘴和 9 点侧后脸链，因此可能跨接错误。此实验只保留前嘴链，用 25 条真实边创建随骨骼变形的内壁。

原下颌权重只作用在 x < -0.37 的前嘴区域。试图将较低面部的下颌权重向后逐渐延伸，保持 Head+Lower_Jaw 原权重总和。`sidejaw` 的侧面首次出现明显开口，但正面过宽并产生锐利嘴角，侧脸可能撕裂。`tapered` 前窄后宽的权重减小了正面开口，却让侧面开口再次变小。两种均不自然。现有舌头的侧面仍很薄，缺少可靠舌根与口底连接。

独立模型，未更新正式网站。只检查静态张/闭，未完成连续动作、动作叠加、GLB 导出、浏览器或设备验证。代码包含本地和 /private/tmp 路径，仅供复现研究。结果尚不适合作成品。
