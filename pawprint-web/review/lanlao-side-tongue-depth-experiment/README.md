# 舌面厚度独立试验

在 `lanlao-lip-sync-study/preview.blend` 上，仅重塑新舌体 204 个顶点，将侧向厚度从约 0.004 调整至 0.006 模型单位；舌长按既有短版保留，其他舌根连接与原脸未移动，各现有形态键随对应舌点平移、收拢键按新形态重算。以可复现构建脚本 `build.py` 输出 `preview.blend`，用 `render.py` 生成正面、侧面及过渡静帧。

结果未合格：正面张嘴口角仍锯齿，帧12仍有黑色断裂，侧面舌体仍近乎细片。单独增加舌厚不能使侧面显露或解决嘴部外壳遮挡；图像不足以证明哪一表面遮挡，需射线或遮挡分析。未测试整个模型碰撞、原动作、GLB和网页；不得接入正式网站。
