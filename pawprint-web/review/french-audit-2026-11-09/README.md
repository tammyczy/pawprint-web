# 法语动作与停止：多轮交叉检查

2026-11-09。所有案例由已知项目背景的 Codex 测试代理编写，均为虚构内容；每条把一个**假设**的模型动作注入服务器护栏，测试的是纯函数，不涉及真实模型、页面、语音、真实用户或动物。标签是作者预先提出的意图，尚未经独立人类标注；这些测试不能推算真实 AI 误动作或用户影响，也不是人类盲测。动作是单动作系统，停止优先不等于执行了用户提出的完整顺序。

## 第一轮

## 测试方法与限制

每次结果均保存题集 SHA-256、部分相关代码的哈希、逐条假设输入动作和实际动作；`run.mjs` 不进行网络请求。**此前测试脚本遗漏了新增依赖 `server/french-physical-stop.mjs` 的哈希：凡在该依赖引入后、final7 之前产生的结果，不能据已保存指纹完整确定当时版本或严格复现。** 这些原文件保留，不伪造事后哈希；final7 运行前已修正脚本并记录该依赖。发现问题后该批题不再作为该版本的独立成绩。抽样刻意集中在法语和已知风险，不代表使用者分布；动词同形词、多动作、否定的含义依上下文而变。前几轮经 Unicode 标准化、大小写及非字母数字剔除的精确匹配，round2 的 b18 与旧题重复；final7 另外有两条重复，未查语义近重复。本测试作者知晓先前迭代；最终未透露给实现者的新样例也不是人类独立盲测。

最终评估和后续源码变化应附加记录，不能覆盖已保存的先前结果。进一步需要人类独立编题和两位标注者审阅初始状态及标签，并分别评估真实模型、网页和设备。
