# 嘴缘共享顶点：形态键与法线对照

2026-11-09，隔离 Blender 4.5.15 实验。以 `review/lanlao-complete-lip-ring-study/preview.blend` 为输入，先移除独立的 ConnectedMouth，再对前方 11 对实际切口边创建直接共享外表面顶点的 33 个内翻面。每个新点拷贝源点的各组骨骼权重、以及 Basis 和两个现有毛发形态键在其源点处的位移。额外对选中嘴缘边设置硬边以隔离新增内壁面和原表面的平滑法线。

### 检查

- 全部 22 条选中的嘴缘边都连到新增内壁面。建模脚本 `build.py` 的 30 个新点逐项检查形态键相对位移误差为零；原有 23603 点在三组键的坐标逐项不变。`check-shape-keys.py` 使用临时路径，需按输出环境调整。
- 对照静态闭嘴正面：仅复制形态键时浅色横线仍可见；仅隔离嘴缘法线时线条在渲染中消失。两者一起时线条也消失。证据图分别为 `shapes-only-front-closed.png`、`normals-only-front-closed.png`、`combined-front-closed.png`。这支持该视角下法线平滑为该线条的重要原因，不证明所有角度都没线。
- 张嘴的正面仍有楔形嘴角；侧面仍像短舌从几乎闭合的下巴穿出，口底及舌根缺少连续结构；本实验没有解决自然张嘴。

这是局部结构与静态诊断，**不得用于正式网站**：仅选了 11 对前缘边，口角和侧面边缘未闭合；没有覆盖所有材质、UV、法线、过渡动作、现有动作、GLB 导出、网页运行或真实设备。脚本输出 `/private/tmp/lanlao-welded-shape-checked.blend`；本目录 `preview.blend` 为保存的结果。两个单变量对照构建和渲染脚本也保存在本目录，使用前需按本机环境调整 /private/tmp 路径。
