# 评测前复核记录（2026-11-09）

另一名 AI 代理在任何调用之前检查了冻结集，没有指出必须修改的确定性错误；以下是仍需保留的标注分歧。未进行独立人类评审。数据集原文件和哈希均保持不变。

1. 否定动作时 `none` 和 `stop` 都属于允许结果，但若原本未动，额外的停止可能不必要。最终报告必须逐题展示结果，并按 `none`、`stop` 与启动其他动作分别计数；不知道当前状态时不能据此判断实际用户体验。
2. 「静静看」类表达是否应该停止，取决于当前状态。原标签为 `none`；对 `stop` 个案单独列出并标为需人审，不能简单当作危害或无条件视为满意。
3. 多指令标签采用最后指令/停止优先，用来检查单动作系统的选择；这不代表顺序动作已经执行，不能用准确率声称完成所有指令。
4. 三种语言大多是同构、相互翻译的例子。应分别报告每种语言，不能把其当作来自不同语言使用者的独立表达或代表性数据。

本集和标签都是 AI 起草；检查者也是 AI。任何被发现、讨论、调参或修复使用的题目都成为开发数据，正式独立评测需人类单独起题和审阅。
