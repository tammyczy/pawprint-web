## 来源和局限

90 条均由 Codex 子代理虚构并初标：简体中文 30、英语 30、法语 30。作者不是参与者，也不是人类评审；其上下文包含本项目对话和此前工作，因此本集**不是人类独立编写、严格隔离的盲测，也不代表真实用户分布**。不得用它声称正式独立准确率或临床安全。正式独立人类题集与至少两人独立语义标注仍需开展。题目不含真实主人材料。

冻结前只检查了 90 条内部完全重复、与 `eval/cases.json`、`eval/intent/train.json`、`eval/safety/cases.json` 的 NFKC、小写、移除非字母数字后的完全相同项：均为 0；**没有进行语义近重复检测**，可能仍有近似案例。生成脚本 `create-dataset.py` 仅为记录来源，包含固定人工编写清单；不要再次运行覆盖已冻结数据。

## 标签和规则

- 每语言包括直接指令 7、间接邀请 3、否定 4、叙述与引用 4、普通对话 3、哀伤对话 3、多指令 3，以及模糊表达 3。
- `allowedActions` 列出可接受的动作：`none` 表示不启动动作；其余为 `come / home / walk / run / wag / jump / stop`。具体动作是已支持的模型动作接口，非新动作需求。
- 否定样例未指定发送前是否正在运动；因此 `none` 与停止已有运动的 `stop` 均视为可接受，任何启动或继续被否定动作均需单列。实际页面的既有待机动作不属于模型选择的指令动作，应另外观察。
- 对两次不同请求，以最后一个明确请求为目标；明确停止优先。这里是拟定标签，不意味着自然语言所有场景都有唯一解释。
- 9 条 `human-review` 模糊样例无预设正确动作，不进入机械准确率分母。人工可记录用户可能意图、是否询问澄清以及不触发动作的代价，保留分歧；其余 81 条为初始机器可评分标签，人工可标注疑义，但不能在观察模型结果后改写本版本标签并继续当作盲测。
- 输入含宠物离世但不包含真人的医疗或危机资料；它不是危机安全测试，也不测回复同理心、事实准确、语音识别或效果。复核应评估响应文字与实际动作是否一致；若绕过网页，应报告不能观察网页级危机分流、渲染和执行。

## 后续测试协议（未执行）

1. 先记录源代码与模型版本、题集 SHA-256、访问方式和调用次数，不泄露凭据；区分规则基线、真实 AI 原始输出、服务器护栏输出、网页实际动作。模型及护栏的行为不可混成一项。
2. 逐题保存输入、允许动作、原始 AI 动作与字幕、护栏输出、错误、超时、耗时和版本；错误不当成 `none`。每个类别、语言分别列请求总数、可评分成功数、正确、失败和服务错误，空分母记不可计算；不得只用成功请求掩盖失败。
3. 机器评分只能检查动作标签，不能证明自然语言语义安全或评价用户体验；身份、隐私、记忆、伤痛等内容须人工独立评审。9 条模糊样例单独记录、由人讨论，不合并进 81 条分母。
4. 一旦本集被用来诊断、修改或选择配置，它就成为开发集；真实使用表现需另一批此前未用于调参、经独立人类审阅的题目和真实世界验证。
