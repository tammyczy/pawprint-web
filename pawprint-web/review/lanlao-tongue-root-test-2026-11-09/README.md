# Tongue root test — 2026-11-09

This is an isolated exploratory Blender copy, based on the prior tongue experiment. The tongue surface was reshaped with a curved profile, a deeper root and rounded width. The jaw and live website were not changed.

The front render shows the tongue is partially obscured by the jaw, creating a horizontal discontinuity. The side render still resembles a narrow protruding strip. This is a failed visual iteration, not a finished or anatomically correct mouth. The initial mesh is not equipped with continuous lip boundaries and an inner mouth; these must be built and properly bound before evaluating natural tongue movement. Both renders use a single open frame; movement, occlusion over all poses, export and real-time behavior remain untested.
