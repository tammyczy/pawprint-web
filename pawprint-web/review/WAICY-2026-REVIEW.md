# Pawprint：WAICY 2026 全项目审查与三轮优化

审查日期：2026-10-24（America/Vancouver）。赛道经项目本人确认：2026 AI Showcase。

## 结论与评分口径

**原始版本桌面预评 62/100；完成本文 V1–V3 后桌面预评 76/100。目标是具备冲击 100 的证据，不是把自评分写成 100。** 评分是基于源代码、测试和可见材料的专业估计，不是官方成绩。原版合理区间约 57–67，改后约 71–81；现场答辩、学生贡献及用户效果未验证，因此不可把点估计当成精确测量。

成熟的视觉与 3D 互动是优势。主要失分来自：需求与影响尚无真实研究、实际模型质量没有独立测量、第三方能力与学生贡献缺少清晰区分、演讲问答尚未观察。继续增加皮肤或动画不能自动补齐这些证据。

- [2026 Guidebook](https://waicy-cdn.wholeren.cn/wp-content/uploads/2026/10/WAICY-2026-Guidebook-2.pdf)：已下载原文件并读取 30 页；相关第 2、3、5、6、7 页已渲染核对，保存在本目录。
- 第 7 页确认 AI 50、Design and Impact 50，并链接详细 rubric。官网首页的另一个 `/rubrics-2/` 链接失效，因此未据此评分。
- [2026 活动页](https://www.waicy.org/waicy-2026/)及手册多数页面一致：12 月 4–6 日比赛。手册第 3 页残留 12 月 5–7 日，不采用这一冲突日期。
- [实际提交表](https://www.waicy.org/2026-submission/)介绍上限 200 词，手册第 5 页写 250。提交草稿采用 **≤200 词项目介绍、≤250 词 AI 使用说明**，同时满足较严格要求。
- 手册第 5–7 页：3 分钟演讲＋3 分钟 Demo＋4 分钟 Q&A；视频英语或英文字幕。AI 使用说明应区分技术、作用与学生自己完成的部分。

- 手册与主页在年龄上限／人数说明不完全一致；先按 1–5 人准备。如成员恰为 18 岁，应在提交前核实资格。

- 默认模型 `public/models/lanlao.glb`：25,317,404 bytes；基础模型 12,939,628 bytes。
- 原始源码快照：`baseline-source.zip`，排除密钥、用户数据、node_modules、构建与二进制模型。共享目录有其他编辑同时发生，快照与本次差异不能当成完整 Git 历史或学生原创证明。

## 技术发现与处理

| 优先级 | 原始问题 | 影响 | 本轮结果 |
|---|---|---|---|
| P1 | `server/app.mjs` multipart 只允许 3 个文本字段，前端发送 name/species/consent/mode 共 4 个 | 正常创建与补视角路线被拒绝，已有测试未覆盖真实表单 | 允许 4 fields/8 parts；覆盖四视角与补视角、私有参考媒体回归 |
| P1 | `server/companion-ai.mjs` 超时仅覆盖收到响应头；语音完整缓冲后才检查大小 | 读体卡住、资源占用、UI 长期等待 | 共享流式 reader，聊天 64KB／语音 5MB；完整读体时限、断连取消、拒绝重定向 |
| P1 | worker 使用旧任务状态；取消／删除与数据库更新存在竞态 | 可能在用户取消后继续外部任务，状态与审计不一致 | 网络前先占用任务；拒绝无效保存；事务化状态＋审计；API 预期状态校验 |
| P2 | 前端 chat 请求无超时；异常响应格式未检查 | send 长期 disabled，错误数据进入历史 | 25s 失效恢复、形状校验、只保存成功轮次；语音 35s 恢复 |
| P2 | 子串匹配将 runway、stopwatch、叙述和英文否定误当动作 | 演示时行为与语言含义不一致 | V2 保守语法，整句否定／上下文先判断，未知表达不动作 |
| P2 | 宠物加载错误藏于折叠详情；原声无法可靠停止 | 用户无法理解失败，音频重叠 | 明确错误状态、参考音频停止与切页清理、麦克风状态语义 |
| P2 | 主场景在隐藏标签页持续绘制 | 无谓 GPU 使用 | 隐藏时跳过 render；加入容器零尺寸保护 |
| P2 | 宠物名字直接混入高优先级 persona 文本，AI 输出还可能被 String 强制转换 | 不可信身份数据及响应更难约束 | 身份作为编码数据、明确不可信输入、严格验证字符串／动作／声音 |
| P2 | README、部署说明仍混有旧端口与“没有 LLM”等历史叙述 | 评委／新维护者误解当前能力 | README 增加当前入口；旧部署记录加历史提示；本报告与提交包给当前状态 |
| 待验收 | 25.3MB GLB、较大 Three.js chunk，聊天等待模型 ready | 网络较慢、低性能手机可能影响演示 | 保留模型和视觉；没有证据支持盲目压缩或声称达到 FPS 目标 |
| 待验收 | 上传媒体参考不参与模型行为学习；结构检查不等于相似度评价 | 容易把存储、动画和个性学习混为一谈 | 在证据页明确披露，不再把它作为已证明的 AI 能力 |

P1/P2 是工程优先级，不是比赛自动扣分规则。完整修复证据见各回归测试和下文验证记录。

## V1：可靠、可恢复的演示

实现：multipart 修复、AI/TTS 流式边界与超时、浏览器超时恢复、严格响应校验、任务状态事务／竞态保护、清晰错误和音频生命周期。persona 增加模拟而非复活、非治疗、避免依赖与不虚构求助电话的边界。

现有优势继续保留：HttpOnly 会话、来源检查、账号所有权、图片真正解码与去元数据、人工授权的付费生成、预算预留、不确定提交不自动重试、GLB 外部 URI 拒绝、原始四个动画及颜色。

**验收边界：** mocked 回归证明应用控制，不能证明供应商真实准确率、敏感对话安全或治疗效果。取消机制不能撤回供应商已经受理的任务。

## V2：能重跑、有失败样例的技术实验

命令：`npm run evaluate`。报告：`public/evidence/command-evaluation.json`。构建前会刷新报告。

数据：55 条开发／探索样例＋13 条独立代码复查发现的对抗样例；修复后都属于开发集，不再称为独立测试集。保存数据、当前 parser 和原版实现的 SHA-256。原版实现冻结于 `eval/baseline-commands.js`。

| 指标 | 原版 | 修订版 |
|---|---:|---:|
| 精确动作标签匹配 | 28/68（41.2%） | 64/68（94.1%） |
| 不应移动样例中的误动作 | 29/32 | 0/32 |
| 仍失败 | 多种否定／叙述／多指令 | 4 条间接或不支持语言表达，均未动作 |

保留失败：`Let's get some fresh air together`、`Show me how fast you can go`、法语间接邀请、西语 `Ven aquí`。这些正是后续比较 LLM 与规则的候选任务；此时没有做真实 LLM 实验，不能写“AI 准确率 94.1%”。

复查过程先发现 `Don't run and jump`、条件句与元语言列表的问题，再加入完整句子守卫及回归测试。这个过程也是迭代证据。小样本开发集的 0 次误动作不是泛化安全保证。

## 从 76 到有机会拿满分：逐项验收

以下是建议的内部高标准，不是官方强制阈值，也不保证评委给分。

1. **AI 18→25：** 先冻结不少于 100 条此前未用于调参的匿名双语意图任务，由独立标注者核对；比较规则、原 prompt、改后 prompt。记录模型与版本、实际 action、语言、格式错误、无请求误动作、延迟中位数/P95、失败恢复及真实调用费用。若有失败，保留错误而不是挑样本。真实供应商调用需另行受控执行，本轮未消费。
2. **技术 21→25：** 对至少一个新宠物完成授权后收费链路，保存每阶段任务与人工检查；对基础／动态模型评估可识别性、骨骼与动画。实测桌面与低性能手机的加载、峰值内存、帧率、断网恢复。先测再决定纹理、LOD、动态加载策略。
3. **问题 6→10：** 按提交包做至少 5–8 名同意参与的成年宠物主可用性试验；静态照片对照和 Pawprint 采用交叉顺序。记录完成率、时间、理解与偏好；可支持可用性结论，不外推心理治疗。
4. **设计 9→10：** 同一设备完成纯键盘、320–390px、放大文字、减少动效、模型失败与离线情景。修复真实阻碍，再录制清晰 Demo。
5. **伦理 9→10：** 记录照片来源／授权、外部供应商处理说明、数据删除演练、合成与原声区分；人工评审涉及宠物身份／失落／依赖的对话样例。prompt 字符串不是模型行为的实证。
6. **展示 6→10：** 学生本人英语或英文字幕完成 3 分钟演讲、3 分钟演示，并能在 4 分钟里解释失败、模型原理、数据与个人贡献。模拟网络失败，准备清楚标注的录制备份。
7. **原创 7→10：** 填写贡献矩阵，把学生、导师、Codex、外部模型／开源库和艺术素材分开。用代码、草图、实验、日记证明个人决策；亲自实现并解释一个针对用户问题的独特改进，不能只说“接了三个 API”。

## 验证与交付

最终自动测试、构建与页面 QA 记录见 `VALIDATION.md`。本次保留三阶段源码快照与差异说明于 `versions/`；它们共用原项目 `public` 大型素材，排除真实 `.env` 和 `.data`，不属于三次公开发布。

剩余限制：自定义 GLB 仍无传输超时、聊天仍等待模型、部分国际化未完整、历史脚本存在本机硬编码、缺少全流程 worker 模拟、供应商花费没有全局硬上限、邀请测试／生产部署／备份与配额仍待专项验收。本地试点不能直接当成已验收的公网产品。

在取得以上证据之前，我不会把 76 写成 100。完成三个代码阶段只是第一步；下一轮最有价值的工作是实际模型实验、用户验证和学生答辩。
