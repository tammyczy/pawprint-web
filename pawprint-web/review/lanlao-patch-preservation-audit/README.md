## UV 补片跨度诊断

对临时 v2 候选中 66 个含新增顶点的外皮补面共 264 条角边检查，79 条 UV 距离大于 0.1，65 条大于 0.25；其中一条模型长度约 0.014 的边跨 UV 0.675。阈值为诊断性选择，不证明全部跨岛或图案成因，但大跨度与鼻下碎裂纹的现象一致。该问题仅涉及候选新增补片，不代表外围原模型 UV 未保留。脚本输入仍是临时候选，重现须改为保存版本。

## v4 闭嘴线射线诊断

投射新贴图后鼻下碎色明显减少，闭嘴细线仍可见。正面 600×600 的闭嘴静帧中，射线在像素(350,377)命中 `Mouth inner graft`，邻近(325,377)及(375,377)命中 `Locally projected muzzle`。这说明至少一处闭合缝中内壁确实暴露，不能仅归因于贴图；不代表每一处线条都同因。原构建在闭嘴时为上/下口缘保留约0.0009模型单位总间距，可能与该处可见缝有关，需通过缩小间距及逐帧退化检查验证。

## v6 闭嘴横线：受光与法线对照

帧1正面闭嘴、600×600截图的 x285–390 / y374–380 像素共742条相机射线，全部首个命中 `Locally projected muzzle`；与 v4 的一次内壁命中不同，v6 横线采样区没有检测到内壁泄露。将补片颜色改成恒定纯色后横线仍存在；改成同色发光不受光材质后横线消失，说明横线涉及受光/法线/自遮挡，不可将此单独解释为贴图颜色。

正面 x330 的光线从 y377 到 y378 跨越候选不同面，几何法线由约(-0.904, 0.166, -0.394)变为(-0.775, 0.140, -0.617)；原参考同一位置在同一原面内法线约(-0.901, 0.164, -0.401)。这是局部抽样而非全表面证明，但支持闭嘴补片存在法线折痕，需进一步对照和解决。上述临时材质修改仅用于诊断，不写入候选或网站。
