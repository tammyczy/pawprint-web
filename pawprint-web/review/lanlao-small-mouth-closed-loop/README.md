# 独立小口缝闭环几何实验

原始未切开模型创建小口缝12段、口角点安全共享；12对唇缘边在原主网格上共享顶点生成内壁。对于四边形在嘴角因重复顶点变为三角形的情况，保留三角而不丢弃，随后只合并坐标、权重及各形态键全部相同的顶点。加极薄口腔内部厚度消除闭合时的零面积；内壁朝向不一致的3个面反转。用户要求的最终自然效果尚未达到。

结构检查：在加厚前后各帧均有36个口内面、0边界、0非流形；加厚前闭嘴帧1/38各3个零面积面，加厚后抽样帧1、8、12、16、20、30、35、38的内壁均为0退化。检查仅限口内材质的局部面，并非完整模型不含其他非流形、无穿插或视觉自然的证明。体积增加只在12个仅连接内壁的顶点，最多0.0003模型单位，Basis及所有现有形态键同步；原脸数据未直接移动。

此前正面渲染嘴角仍尖锐，侧面几乎没有开口；此版尚需短舌与口底实际桥接、细致口型、闭嘴图像对照、连续动画及GLB/网页验证。该文件没有接入正式网站。

复现脚本引用 /private/tmp 中间产物，必须按本机环境调整路径。`preview.blend` 是最终独立状态。验收脚本亦需将其输入路径改为此目录的模型。此前人造舌体随开合缩放，不能当作口底连接。
