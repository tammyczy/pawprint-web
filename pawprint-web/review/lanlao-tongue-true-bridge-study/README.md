# 共享口壁顶点的舌根连接实验（未达到自然效果）

本独立副本将短舌的闭合截面并入原脸网格，并以两组连接面共享原口腔下壁三个顶点，代替以前舌头独立悬空。原网格 23,790 个顶点的 Basis 与两项毛发形态键逐点坐标误差均为零，原有骨骼权重误差为零；该检查不等于验证实际动画和形态键运行。实验新增204个顶点，每个新增点在原有三项 shape keys 中均保留对应值。

帧1闭嘴、帧20张口正侧静帧已渲染。口底共享边是真实拓扑连接，但口腔正面仍过宽、侧面舌头像细片，视觉不够自然。缩舌形态键、舌根条带的中间动画、舌面自交、既有动作、GLB、浏览器和手机仍未验证，不能接入正式网站。生成脚本目前使用 /private/tmp/lanlao-oriented-mouth.blend，可用之前对应的独立口腔基底替换；正式网站模型未改。
