# 焊合非嘴部切口并尝试侧向开合：独立实验

基于旧 35 点内壁版本，按真实网格边邻接区分 26 点前嘴唇和 9 点不相连后脸链；此副本的内壁仅覆盖前嘴真实边，避免将不相邻位置按横向坐标排序造成跨接。

后脸链 14 个重复顶点焊合前，逐项核对原有三个形态键坐标完全一致，骨骼权重最大差约 7.5e-9；焊合后三个形态键保留。测试用侧向形态键按前后深度及横向距离平滑控制 35 个脸部顶点、24 个内壁顶点。闭嘴正面与焊合前静态渲染每通道最大差 1（600×600，平均每通道差低于 0.0004）。

张嘴时，侧脸后方额外裂缝消除；但正面嘴角呈明显黑色尖楔、开口不自然，侧面仍像舌头从闭合下巴伸出。未达到自然效果，不得接入网站。没有连续运动、动作叠加、GLB 导出、性能和浏览器检查。实验构建脚本含 /private/tmp 中间路径。正式模型未修改。

补充椭圆口型试验：对隔离焊合副本测量张口帧20的上下唇间距，以近椭圆下唇目标生成独立形态键，覆盖 33 个脸部点、10 个内壁点；闭嘴无该形变。渲染显示嘴角仍是尖锐黑色裂口，侧面仍是舌片，效果不够自然。该曲线只改变既有前唇表面，未建立完整侧面唇缘、口底或舌根；不得接入网站。

## 可复现输入和诊断

`mainlip.blend` 为依据实际连通边创建内壁的隔离基底，来自 `../lanlao-complete-lip-ring-study/preview.blend`。`weld-cheek.py` 从 mainlip 生成 `welded.blend`；`build-morph.py`、`wide-morph.py`、`ellipse-lip.py` 分别生成不同形态键实验，输出到本目录的 `rebuild-*.blend`。`connected-build.py` 从 35 点源模型重建 mainlip；`graph-inspect.py` 可输出 26 与 9 两个分量。运行 Blender 后所有结果仍需自行渲染及复核。真实邻接检查确认两个不相连的链，不能单凭排序把它们连接为一条完整的嘴部边环。这里没有构建缺失的侧面口角。
