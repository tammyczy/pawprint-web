01 / THE QUESTION

Can a digital keepsake become
a simple, personal interaction?

Some people who have lost a pet may want a personal way to remember a familiar companion. Pawprint combines a recognizable model with short conversations and controllable movement. This is a design hypothesis; user benefit has not yet been established in a participant study.

Intended use: a creative keepsake and playful companion. It does not recreate an animal’s consciousness or establish that a pet feels, thinks, or speaks this way.
How pet-loss research shaped the design

A qualitative review describes the importance of the human–animal relationship and social recognition of grief. In a survey of 429 bereaved owners, social support was associated with lower reported distress; that association does not establish cause and effect. Pawprint acknowledges the relationship and offers a user-initiated path to human support.

A review of continuing bonds describes varied experiences of remembrance. Pawprint therefore lets people choose whether to interact, quietly watch, or write and download their own words. The optional AI draft is editable and its excerpts are provided for checking, not as proof of accuracy.

These studies informed design choices; they did not evaluate Pawprint, its 3D companion, or its AI. We still need consented user feedback and independent evaluation to learn whether the experience is comfortable or useful. No therapeutic effect is claimed.

02 / WHERE AI FITS

Three model services.
One bounded experience.

01 / LIKENESS

Photos → candidate 3D

Consented photos are decoded and re-encoded on the server. Tripo provides pretrained reconstruction, rigging and supported animation. Generated views are inferred and need owner approval.

AI: image-to-3D inference
Application: access, budget, job states, review
02 / INTENT

Message → structured reply

A pretrained language model proposes a short caption and one action from an allowlist. The server validates the response and applies a conservative action gate; the browser maps allowed actions to existing animations. Clearly recognized privacy questions receive a labeled system notice instead of a model reply. An optional memory draft displays owner-provided excerpts for review; an excerpt alone does not prove the draft is accurate.

AI: language and intent generation
Application: validation, action gate, system notices and animation
03 / EXPRESSION

Caption → voice + movement

Text-to-speech reads the caption using a selected synthetic voice. Three.js renders supplied animations; offline rules support a deliberately smaller set of commands.

AI: synthetic speech
Application: playback, stopping, rendering, fallback
What is learned, and what is programmed?

These models were pretrained by external providers. This project does not claim to have trained a foundation model, an emotion detector or a voice clone. Prompts, service integration, validation, privacy controls, 3D behavior and evaluations are inspectable application work. Student authorship and assistance must be disclosed separately in the submission.

Five Big Ideas connection: perception (third-party image or speech processing), representation and reasoning (3D representation and structured action decisions), learning (external pretrained models), natural interaction (language and voice), and societal impact (consent, emotional framing and accessible alternatives).

What happened when we tested the real language model?

On November 9, 2026, we sent 45 author-written, fictional single-turn cases to the configured model in each of two development runs. All 45 requests returned a response in each run. That is a request-completion count, not an accuracy or safety score. An independent AI assistant reviewed the outputs; there was no independent human blind review.

One earlier reply chose an unrequested approach during a sad conversation; another repeated instruction-like text supplied as a pet name. We changed the handling of obvious instruction-like names and added a conservative action gate. Later browser testing also exposed a reply promising to approach while returning no action; a single clearly recognized command can now supply the missing action. A system-adjusted caption is labeled.

In a separate exploratory set of 90 AI-authored multilingual cases, the previous gate rejected all 21 labeled direct commands. After using the same cases to improve the gate, we replayed the original model outputs: 79 of 81 automatically labeled cases matched, while nine ambiguous cases were excluded. Two Chinese invitations remained blocked. Because this set guided changes, the replay is a development result, not an independent accuracy estimate; further adversarial review found possible misinterpretations.

Follow-up French checks identified missed stop requests and text-navigation phrases that could be mistaken for physical jumps. We refined the gate and local stop controls, and preserved failures and limitations. A subsequent small AI-authored set was checked with hypothetical model outputs; its labels have not been reviewed by independent humans. For requests involving multiple actions, stopping takes priority and the interface explains that only one action is performed.

We tested memory drafts using fictional text too. One run rejected a draft because its excerpt did not exactly match the original; a later run generated all seven examples. A matched excerpt is only a clue for human review, not proof that the sentence is faithful. Available outputs, versions and failures are retained in the project review files; the provider excerpt from one rejected draft was not captured. This is not a participant study or a therapeutic evaluation.

04 / TRUST IS PART OF THE DESIGN

Personal, without
pretending to be a real pet.

Consent & data

Use photos and recordings you have permission to use. Uploads, models and jobs are private to the local workspace or account. Original reference files stay on the server until deleted; generation sends photos to the configured provider. Chat text goes to the language service; voice text goes to the speech service.

Control & choice

The microphone starts on click. Browser recognition may use its provider. Buttons and typed commands offer alternatives. AI voice is labeled synthetic; original reference audio is separate. Generation depends on the configured mode: local runs require operator approval; enabled cloud runs can be started by the user. Generated results still need review.

Emotional boundaries

This is a simulation for creativity and companionship, with no demonstrated therapeutic effect. It should support human relationships. Owners can stop interaction or delete a project. Sensitive messages require careful human review beyond this command experiment.

Honest limitations

Photo reconstruction can invent unseen details. New pets do not automatically gain every Lanlao animation. External services can fail; local rules understand fewer phrases. Detailed models may load slowly on phones. No real participant study, provider quality benchmark or clinical evaluation is included.

05 / THREE IMPLEMENTED ITERATIONS

Build. Measure. Explain.

  1. V1 / Reliability

    Repair multipart uploads; bound chat and voice requests; validate provider data; stop audio and protect rendering lifecycles. Regression tests use isolated data and mock providers.

  2. V2 / Measurement

    Replace broad substring triggers with conservative commands. Save original versus revised results, dataset hash and every failure. No independent model benchmark is implied.

  3. V3 / Reviewability

    Expose this evidence page, architecture, known limits and repeatable demonstration. The submission kit includes a contribution template awaiting verification, an interview protocol and the remaining acceptance gates.

Next evidence gates: independent intent cases and human review of real model outputs; consented usability sessions; approved generation acceptance; student contribution records; a timed English demo and live Q&A.
