01 / THE QUESTION

Can a digital keepsake become
a simple, personal interaction?

Pet owners may want a way to revisit a familiar companion when they are apart. Pawprint combines a recognizable model with short conversations and controllable movement. This is a design hypothesis; user benefit has not yet been established in a participant study.

Intended use: a creative keepsake and playful companion. It does not recreate an animal’s consciousness or establish that a pet feels, thinks, or speaks this way.

02 / WHERE AI FITS

Three model services.
One bounded experience.

01 / LIKENESS

Photos → candidate 3D

Consented photos are decoded and re-encoded on the server. Tripo provides pretrained reconstruction, rigging and supported animation. Generated views are inferred and need owner approval.

AI: image-to-3D inference
Application: access, budget, job states, review
02 / INTENT

Message → structured reply

A pretrained language model returns a short caption and one action from an allowlist. The server validates the result; the browser maps it to existing animations.

AI: language and intent generation
Application: schema, time limits, animation control
03 / EXPRESSION

Caption → voice + movement

Text-to-speech reads the caption using a selected synthetic voice. Three.js renders supplied animations; offline rules support a deliberately smaller set of commands.

AI: synthetic speech
Application: playback, stopping, rendering, fallback
What is learned, and what is programmed?

These models were pretrained by external providers. This project does not claim to have trained a foundation model, an emotion detector or a voice clone. Prompts, service integration, validation, privacy controls, 3D behavior and evaluations are inspectable application work. Student authorship and assistance must be disclosed separately in the submission.

Five Big Ideas connection: perception (photo input), representation and reasoning (3D representation and structured actions), learning (external pretrained models), natural interaction (language and voice), and societal impact (consent, emotional framing and accessible alternatives).

04 / TRUST IS PART OF THE DESIGN

Personal, without
pretending to be a real pet.

Consent & data

Use photos and recordings you have permission to use. Uploads, models and jobs are private to the local workspace or account. Original reference files stay on the server until deleted; generation sends photos to the configured provider. Chat text goes to the language service; voice text goes to the speech service.

Control & choice

The microphone starts on click. Browser recognition may use its provider. Buttons and typed commands offer alternatives. AI voice is labeled synthetic; original reference audio is separate. Generation requires operator approval and a budget reservation.

Emotional boundaries

This is a simulation for creativity and companionship, with no demonstrated therapeutic effect. It should support human relationships. Owners can stop interaction or delete a project. Sensitive messages require careful human review beyond this command experiment.

Honest limitations

Photo reconstruction can invent unseen details. New pets do not automatically gain every Lanlao animation. External services can fail; local rules understand fewer phrases. Detailed models may load slowly on phones. No real participant study, provider quality benchmark or clinical evaluation is included.

05 / THREE IMPLEMENTED ITERATIONS

Build. Measure. Explain.

  1. V1 / Reliability

    Repair multipart uploads; bound chat and voice requests; validate provider data; stop audio and protect rendering lifecycles. Regression tests use isolated data and mock providers.

  2. V2 / Measurement

    Replace broad substring triggers with conservative commands. Save original versus revised results, dataset hash and every failure. No successful model benchmark is implied.

  3. V3 / Reviewability

    Expose this evidence page, architecture, known limits and repeatable demonstration. The submission kit records student contribution, an interview protocol and the remaining acceptance gates.

Next evidence gates: independent intent cases and real model evaluation; consented usability sessions; approved generation acceptance; student contribution records; a timed English demo and live Q&A.
