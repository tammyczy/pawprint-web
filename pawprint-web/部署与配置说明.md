## 测试预算与真实生成

`.env` 已配置本轮预算 1500 API credits；收费开关默认关闭。文件已加入 `.gitignore`，不会进入网站构建输出。

先在项目目录运行 `node server/check-config.mjs` 只读验证余额。余额和授权确认后，才将 `ALLOW_PAID_GENERATION` 改为 `true`。在工作室创建任务，复制任务编号，运行：

```powershell
npm run process -- 任务编号 --confirm-tripo-charges
```

按目前官方标准参数，生成 30 + 绑定 25 + 一个动画 10 = 65 积分；检查免费。每个任务保守预留 100 积分，累计不超过 1500。失败/不确定请求不自动释放预留额，避免重复消费。外部价格变化无法用本地代码强制限制供应商账单，因此首次启用前须再次确认价格；每阶段实际扣费缺失或超预期时停止下一收费步骤。

选择先补 AI 四视角时增加 10 积分，整条标准流程预计 75 积分，仍在单任务 100 积分预留内。四视角生成后 worker 会退出等待用户确认；确认后站长用相同任务编号再次运行，不重复生成四视角、不重复预留预算。首次付款调用尚未验收。

不得直接删除预算账本来重复测试。`SUBMISSION_UNCERTAIN` 需核对第三方任务后人工恢复，不能重建任务绕过。异常退出留下 `.data/worker.lock` 时，先确认没有 worker 进程，再做恢复。普通查询网络中断可以用相同任务编号恢复，不重复提交已保存编号的请求。

## 公网部署的下一步

没有域名可以先选择服务商分配的测试地址；正式稳定上线推荐配置自己的域名与 HTTPS 隧道。当前未创建公开隧道，避免把未验收的账号/上传服务暴露到公网。

确定公网入口后：设置 `.env` 的 `APP_ORIGIN=https://你的地址`，重启；在隧道入口设置访问控制/限流，先用邀请测试。服务继续只监听 127.0.0.1，隧道只转发 8787；不公开 Blender MCP、桌面远程控制或数据库端口。公网前补上邮件验证/重置、对象存储备份、全局存储配额和集中限流，完成安全复核。

密钥只留在服务端 `.env`，照片/模型/数据库保存在 `.data`，不可上传为静态网站资源。备份时保护两者，分享项目时排除 `.env`、`.data`、日志与 `node_modules`。
