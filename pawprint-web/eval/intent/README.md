# 意圖分類小模型（intent model）

## 這是什麼

一個可以由團隊自己訓練、自己檢查的小型機器學習模型：把使用者打的一句話分類成寵物動作 `come / home / walk / run / wag / jump / stop`，或 `none`（不該動）。

- **模型**：多類別邏輯斯迴歸（softmax regression），特徵是字元 1–3 gram（NFKC 正規化、轉小寫、詞邊界加 `_` 標記；中文字以連續漢字為一段）。約 1,200 個特徵、模型檔約 40 KB，可直接在瀏覽器執行（`src/intent-model.js`，`public/models/intent-model.json`）。
- **混合策略** `hybridCommand`：規則（`src/commands.js`）優先；規則因**否定**或**引號**而不動時，模型**永遠不能推翻**；其餘情況只有模型信心 ≥ 門檻（目前 0.75）才採用。
- **訓練資料** `train.json`：315 句種子句子（簡中、繁中、英、法；約三分之一是 none）。**這些句子是 AI 助手起草的草稿**（`source: "seed-claude-draft"`），團隊必須逐句審查、改標、刪除不自然的句子，並加入自己寫的句子（把 `source` 改成自己的名字），才能說是團隊的成果。

## 指令

```bash
node eval/intent/train.mjs          # 訓練，輸出 model.json 與 public/models/intent-model.json
node eval/intent/compare.mjs        # 比較 舊規則 / 現行規則 / 分類器 / 混合 / LLM（有 OPENAI_API_KEY 才跑）
node --test intent-model.test.js    # 單元測試
```

- `train.mjs` 會檢查訓練句和 `eval/cases.json` 是否**完全相同或高度相似**（字元相似度 ≥ 0.85，忽略標點和寵物名字），發現就拒絕訓練。
- 訓練是確定性的（固定亂數種子），同一份資料一定得到同一個模型；測試會驗證這點。
- 門檻只用 `train.json` 的 5 折交叉驗證來選（錯誤動作率 ≤ 5% 中最準的），**沒有**用 `cases.json` 調。
- 結果寫在 `public/evidence/intent-comparison.json`（含資料集 sha256、混淆矩陣、分組結果、學習曲線、門檻掃描）。
- 盲測方法見 [`盲測集填寫說明.md`](./盲測集填寫說明.md)。

## 對應 AI4K12「五大概念」的 Learning（機器學習）

| AI4K12 Big Idea 3：Computers can learn from data | 本專案對應 |
| --- | --- |
| 資料決定模型學到什麼 | `train.json` 由團隊標註；改資料就會改變行為 |
| 特徵表示 | 字元 n-gram：電腦「看到」的是字串片段，不是意思 |
| 訓練＝調整參數讓錯誤變小 | 隨機梯度下降最小化交叉熵，每個特徵對每個標籤一個權重 |
| 要用沒看過的資料評估 | 5 折交叉驗證、開發集與盲測集分開 |
| 資料越多通常越好 | 學習曲線：10% → 100% 資料，交叉驗證準確率約 0.38 → 0.70 |
| 模型會犯錯，要有安全設計 | 機率輸出＋門檻；否定句由規則鎖定，不給模型推翻 |

## 目前結果（開發集，非盲測）

在 `cases.json`（55 句，開發集）上：舊規則 0.455、現行規則 0.927、分類器單獨 0.782（有 3 次錯誤動作）、混合 0.927（0 次錯誤動作）。混合系統在開發集上**沒有**比現行規則更好：剩下的 4 個失敗句都是刻意的困難句，訓練資料也刻意沒有寫它們的改寫版。混合系統的價值出現在規則沒涵蓋的說法上：在 `train.json` 的交叉驗證中，混合系統準確率約 0.58，而規則只有約 0.35，代價是錯誤動作率約 4%。數字以 `compare.mjs` 最新輸出為準。

## 誠實的限制

- 資料很少（315 句），而且是 AI 起草、同一個作者的風格；交叉驗證分數會偏樂觀，真實使用者的說法會更多樣。
- 起草訓練資料的人看過 `cases.json`，雖然有自動檢查沒有重複，開發集分數仍不是獨立證據；**只有盲測集才算**。
- 字元 n-gram 不懂語序和否定（「不要跑」和「跑」很像），所以否定必須靠規則把關；分類器單獨使用會有錯誤動作。
- 只支援四種書寫方式；西班牙文等其他語言基本上會判成 none 或亂猜。
- 這不是大型語言模型，也不理解情緒；它只是把句子對到 8 個標籤之一。
- 尚未接到網站介面；接入前應先完成團隊審查和盲測。
